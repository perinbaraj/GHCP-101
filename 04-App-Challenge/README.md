# Section 4: App Challenges — Build Real Applications

**Duration:** 4-6 hours total | **Tech Stack:** Your choice for each project | **Copilot Focus:** Planning, implementation, testing, documentation

---

## 🎯 Overview

Apply everything you've learned in Sections 1-3 by building **real, functional applications**. You have flexibility in **tech stack** — use what you're comfortable with or want to learn.

### **Challenge Structure:**
- **Challenges 1-3:** Weather App (interconnected)
- **Challenge 4:** Movie Booking System (independent)

---

## 📚 Challenge Selection

### **Option A: Build the Complete Weather App** (3-4 hours)
Do all 3 interconnected challenges:
1. ✅ Frontend (React, Vue, Angular, etc.)
2. ✅ Backend (Node, Python, C#, etc.)
3. ✅ Database (PostgreSQL, MongoDB, etc.)

**Benefits:** Learn full-stack development, practice system integration

---

### **Option B: Build the Movie Booking System** (2-3 hours)
Do Challenge 4:
1. ✅ Complete application with all features

**Benefits:** Deep dive into complex business logic, real-world scenarios

---

### **Option C: Mix & Match**
- Do 1-2 Weather App challenges + Movie Booking (1-2 hours each)
- Or focus on just the backend/database layers

**Benefits:** Customize to your learning goals

## 🏆 Final Tips

1. **Start Simple:** Build MVP first, add features later
2. **Use Copilot:** Let it help with boilerplate, patterns, debugging
3. **Test as You Go:** Don't build everything then test
4. **Commit Often:** Good Git history shows progress
5. **Ask for Help:** Use Copilot for explanations and guidance
6. **Have Fun:** Build something you're proud of!
