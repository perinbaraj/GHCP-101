# 60-Minute App Challenge: Todo API

**Difficulty:** Intermediate | **Time:** 30-45 minutes | **Copilot Focus:** Planning + Implementation + Testing

---

## 🎯 Challenge Overview

Build a **fully functional RESTful Todo API** in 30-45 minutes using GitHub Copilot extensively.

### **Requirements:**
- ✅ In-memory data store (no database required)
- ✅ CRUD endpoints for todos
- ✅ Proper HTTP status codes
- ✅ Input validation
- ✅ Unit tests (70%+ coverage)
- ✅ XML documentation
- ✅ Clean Git history with meaningful commits

---

## 📋 Feature Requirements

### **Endpoints:**

| Method | Route | Description |
|--------|-------|-------------|
| GET | `/api/todos` | Get all todos |
| GET | `/api/todos/{id}` | Get todo by ID |
| POST | `/api/todos` | Create new todo |
| PUT | `/api/todos/{id}` | Update todo |
| DELETE | `/api/todos/{id}` | Delete todo |
| GET | `/api/todos/status/{status}` | Filter by status |

### **Todo Model:**
```json
{
  "id": 1,
  "title": "Learn Copilot",
  "description": "Master GitHub Copilot for .NET",
  "isCompleted": false,
  "createdDate": "2024-01-29T10:00:00Z",
  "dueDate": "2024-02-05T17:00:00Z"
}
```

### **Validation Rules:**
- ✅ Title is required and max 100 characters
- ✅ Description is optional, max 500 characters
- ✅ Due date must be in the future
- ✅ ID must be positive

## 🚀 Quick Start

1. **Create ASP.NET Core project:**
   ```bash
   dotnet new webapi -n TodoAPI
   cd TodoAPI
   ```

2. **Create project structure:**
   ```
   Models/
   ├── Todo.cs
   Services/
   ├── ITodoService.cs
   ├── TodoService.cs
   Repositories/
   ├── IRepository.cs
   ├── InMemoryRepository.cs
   Controllers/
   ├── TodoController.cs
   ```

3. **Use Copilot Chat** for each file:
   - Ask Copilot to generate each class
   - Review and accept suggestions
   - Use `/tests` for unit tests
   - Use `/doc` for XML comments

4. **Test manually** using Postman or curl:
   ```bash
   curl -X GET http://localhost:5000/api/todos
   curl -X POST http://localhost:5000/api/todos \
     -H "Content-Type: application/json" \
     -d '{"title":"Buy milk","isCompleted":false}'
   ```

5. **Commit and submit PR**
