## ✅ Features Implemented

### Endpoints

- [ ] GET /api/todos — Returns all todos (200 OK)
- [ ] GET /api/todos/{id} — Returns single todo (200 OK) or (404 Not Found)
- [ ] POST /api/todos — Creates new todo (201 Created) with validation
- [ ] PUT /api/todos/{id} — Updates todo (200 OK) or (404 Not Found)
- [ ] DELETE /api/todos/{id} — Deletes todo (204 No Content) or (404 Not Found)
- [ ] GET /api/todos/status/{status} — Filters todos by status

### Validation

- [ ] Title required and max 100 characters
- [ ] Description optional, max 500 characters
- [ ] Due date must be in future (if provided)
- [ ] ID must be positive
- [ ] Invalid input returns 400 Bad Request with error message
- [ ] Not found returns 404 Not Found
